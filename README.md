## 🛠️ Troubleshooting: Common Issues & Fixes

### Issue 1: "Windows doesn't recognize the hotspot"

**Fix**: Try a different USB port (preferably USB 3.0, the blue one). Also make sure the hotspot is **on** (not just charging)) before pluggingin.





### Issue 2: The black window closes immediately

**Fix**: Right-click on the `run.bat` file and choose **"Run as administrator"**. This gives it permission to work properly.



### Issue 3: It says "Device not found"

**Fix**: Unplug the USB, wait 10 seconds, then plugit back in. Make sure you're using the **original cable** that came with the hotspot—some cables only chargeand don't transfer data.



### Issue 4: The process gets stuck at 50%

**Fix**: Don't unplug anything. Wait another 2 minutes. Sometimes it just takes longer on older computers. If it's stuck over 5 minutes, close the window, restart your computer, and try again from Step 4.
